# 알바생용 메뉴 레시피 바로 찾기

메뉴 이름(또는 초성)만 입력하면 음료 사진과 레시피가 바로 나오는 Java Swing 프로그램입니다.

## 폴더 구성
- `src/SwingMain.java` : 앱 창(화면). 검색창, 메뉴 목록, 레시피 카드, 등록·수정·삭제·비밀번호 변경 창
- `src/RecipeService.java` : 검색·등록·수정·삭제·저장 규칙을 한곳에 모은 클래스 (화면은 이것만 부른다)
- `src/Recipe.java` : 메뉴 하나의 데이터 (메뉴명, 카테고리, 사이즈별 재료, 레시피, 토핑)
- `src/RecipeBook.java` : 레시피 관리, 띄어쓰기를 무시한 검색, 초성 검색, 카테고리별 묶기
- `src/RecipeFileStore.java` : `recipes.txt` 저장과 불러오기
- `src/AdminAuth.java` : 관리자 비밀번호 확인·변경 (`admin.txt`)
- `src/AppPaths.java` : recipes.txt 위치를 찾는다 (VS Code에서 상위 폴더를 열어도 동작)
- `recipes.txt` : 시작용 예시 메뉴 8개
- `images/` : 음료 사진. 예시 메뉴 8개의 그림이 들어 있고, 앱에서 등록한 사진도 여기에 복사됩니다
- `run-app.bat` / `run-app.sh` : VS Code 없이 더블클릭으로 실행 (Windows / Mac·Linux)
- `.vscode/launch.json` : VS Code에서 F5로 앱 창을 실행하는 설정

## 실행 방법 (JDK 11 이상 필요)

### VS Code에서 실행하기 (추천)
1. VS Code에서 `파일 → 폴더 열기`로 `recipe-finder` 폴더를 엽니다. (Extension Pack for Java가 설치되어 있어야 합니다)
2. **F5**를 누릅니다. (`SwingMain.java`를 열고 `main` 위의 **Run**을 눌러도 됩니다)
3. "메뉴 레시피 바로 찾기" 창이 뜹니다. 터미널에 입력할 것은 없습니다.
4. 창의 X를 누르면 프로그램이 끝납니다.

### 더블클릭으로 쓰기 (VS Code 없이)
`run-app.bat`을 더블클릭하면 컴파일 후 창이 뜹니다. (Mac/Linux는 `./run-app.sh`)

### 터미널에서 직접 실행할 때
```
javac -encoding UTF-8 -d out src/*.java
java -cp out SwingMain
```

## 사용법
- 위쪽 검색창에 메뉴 이름이나 초성을 치면 바로 결과가 나옵니다. 결과가 하나면 레시피가 바로 열립니다. Esc를 누르면 검색어가 지워지고 전체 목록으로 돌아갑니다.
- 왼쪽 목록에서 메뉴를 누르면 오른쪽에 재료, 레시피, 컵 위 토핑이 나옵니다.
- 사이즈가 여러 개인 메뉴는 사이즈 버튼(기본 20oz)으로 바꿔 봅니다. `전체`를 누르면 모든 사이즈의 재료가 나옵니다.
- `+ 레시피 등록`으로 신메뉴를 등록합니다. 사이즈를 체크하면 사이즈마다 재료 칸이 생깁니다.
- `사진 선택…`으로 음료 사진(jpg, png, gif)을 고르면 레시피 카드와 왼쪽 목록에 사진이 나옵니다. 사진은 없어도 됩니다.
- 수정·삭제는 레시피 아래 버튼을 누르고 관리자 비밀번호를 입력합니다.

## 음료 사진
- 등록·수정 창에서 고른 사진은 저장할 때 `images` 폴더로 복사됩니다. 원래 사진 파일은 지우거나 옮겨도 됩니다.
- 사진 파일 이름은 영문·숫자로 자동으로 정해집니다(한글 파일 이름은 압축을 풀거나 옮길 때 깨질 수 있어서). 예: `menu_1a2b3c4d.png`
- 수정에서 다른 사진을 고르면 바뀌고, `사진 빼기`를 누르면 빠집니다. 바꾸거나 뺀 옛 사진 파일은 자동으로 지워집니다.
- 예시 메뉴 8개의 사진은 음료 모양을 간단히 그린 예시 그림입니다. 매장에서 찍은 사진으로 바꿔 쓰면 됩니다.
- 프로젝트 폴더를 옮길 때는 `images` 폴더도 함께 옮겨 주세요.

## 관리자 비밀번호
- 레시피 수정·삭제와 비밀번호 변경은 관리자 비밀번호가 필요합니다. 등록은 누구나 할 수 있습니다.
- 처음 실행하면 `admin.txt`가 기본 비밀번호 `1234`로 만들어집니다. 위쪽 `비밀번호 변경` 버튼에서 바꿔 주세요.
- 틀리면 입력 창에 빨간 글씨로 안내가 나오고, 입력한 내용은 그대로 남습니다.

## 검색
- 띄어쓰기는 무시합니다: `바닐라 라떼` = `바닐라라떼`
- HOT/ICE는 메뉴 이름 앞에 붙습니다: `ICE 바닐라라떼`. `아이스`, `핫`으로 입력해도 찾습니다.
- `바닐라라떼`만 입력하면 HOT과 ICE 두 메뉴가 목록에 나오고, 눌러서 고릅니다.
- 초성으로도 찾습니다: `ㅂㄴㄹㄹㄸ`, `ㅂㄴㄹ` → 바닐라라떼. 된소리는 예사소리와 같게 봅니다(`ㅂㄴㄹㄹㄷ`도 됨).

## 사이즈별 레시피
- 컵 사이즈는 14oz, 20oz, 32oz이고 기본은 20oz입니다.
- 등록할 때 이 메뉴에 있는 사이즈를 체크합니다. 아무것도 체크하지 않으면 20oz 하나로 정해집니다. 14oz만, 32oz만 있는 메뉴도 등록할 수 있습니다.
- 체크한 사이즈마다 재료를 입력합니다. 레시피(제조 순서)와 토핑은 사이즈와 상관없이 같습니다.
- 사이즈 이름은 `Recipe.java`의 `SIZE_OPTIONS`, `BASE_SIZE`에서 바꿀 수 있습니다.

## 레시피 파일 형식
메뉴마다 메뉴 → 카테고리 → (사진) → 재료 → 레시피 → 토핑 순서로 적습니다. `사진:` 줄은 사진이 있는 메뉴만 적습니다.
```
메뉴: ICE 바닐라라떼
카테고리: 커피
사진: images/ice_vanilla_latte.png
재료:
- 에스프레소 2샷
- 바닐라시럽 20ml
레시피:
1. 컵에 바닐라시럽을 넣는다
2. 얼음을 채우고 찬 우유를 붓는다
토핑: 없음
```
토핑이 있으면 `토핑:` 아래에 `- 휘핑크림 2바퀴`처럼 적습니다.
20oz만 있는 메뉴는 `재료:` 한 칸만 적고, 그 밖의 메뉴는 `재료(14oz):`, `재료(20oz):`, `재료(32oz):`처럼 있는 사이즈마다 적습니다(14oz만 있으면 `재료(14oz):` 한 칸).
`#`으로 시작하는 줄은 주석입니다.

메모장으로 고칠 때 참고:
- 앱 창이 켜져 있어도 메모장으로 저장하면 2초 안에 창에 반영됩니다.
- `메뉴 :`처럼 콜론 앞에 띄어쓰기가 있거나, 재료·레시피 줄 앞에 `- `, `1. `이 없어도 읽습니다. `재료(20온즈):`도 `20oz`로 읽습니다.
- 메모장에서 ANSI로 저장해도 읽습니다(다음 저장 때 UTF-8로 바뀜).
- 메모장으로 사진을 넣을 때는 사진 파일을 `images` 폴더에 넣고 `사진: images/파일이름.png` 줄을 카테고리 아래에 적습니다(파일 이름은 영문 권장).
- 형식이 틀려 건너뛴 메뉴가 있으면 창 위쪽 주황빛 안내 칸에 몇 번째 줄인지 나옵니다. 그 상태로 앱에서 저장하면 원래 파일을 `recipes_backup.txt`로 남겨 둡니다.
- 창 맨 아래에 지금 읽고 있는 recipes.txt 위치가 나옵니다.

## 화면 색
연노랑 계열입니다. 색을 바꾸려면 `SwingMain.java` 위쪽의 색 상수(`BG`, `HEADER`, `BRAND` 등)만 고치면 됩니다.

## 문제가 생기면
- 사진이 안 보임: 카드에 나오는 위치에 사진 파일이 있는지 확인합니다. `images` 폴더가 recipes.txt와 같은 폴더에 있어야 합니다.
- 한글이 네모로 보임: 한글 글꼴을 찾지 못한 것입니다. Windows는 맑은 고딕, Mac은 애플 SD 고딕을 자동으로 씁니다.
- 메뉴가 하나도 없음: 창 맨 아래 파일 위치가 recipe-finder 폴더의 recipes.txt인지 확인합니다. VS Code에서 recipe-finder 폴더를 열고 실행하세요.
